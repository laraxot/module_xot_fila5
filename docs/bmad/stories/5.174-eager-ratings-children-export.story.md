# 5.174 (Xot) — Eager `ratings.children` in export

## Perché

`ratings_by_id.*.xls_export_value` risolve il figlio selezionato dalla relazione
`children`. Senza eager, ogni cella può fare `children()->exists()` / `find()`.

`modifyQuery()` carica già `ratings` e `ratingMorphs`. Aggiungere
`ratings.children` **solo se** il model ha `ratings` (stesso pattern
`method_exists`).

## AC

- [x] `with` include `ratings.children` quando esiste `ratings`
- [x] Host senza ratings: comportamento invariato
- [x] Usato da `ExportXlsAction` e canale xlsx (`XlsFieldsExporter`)
- [x] Pest `modifyQuery eager-load ratings, ratings.children` in XotBaseExporterTest

## Test

Assert su reflection/source o test che `modifyQuery` sulla query di uno stub
con `ratings()` chieda `ratings.children` (se già esiste harness exporter).
