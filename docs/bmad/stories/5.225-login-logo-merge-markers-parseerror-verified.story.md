# 5.225 — Logo login non visibile (terza causa: merge markers → ParseError)

## Sintomo

Utente: "non si vede il logo in `http://personale2022.prov.tv.local/admin/login`,
può essere colpa del git lfs". Host = **10.100.200.15** (produzione, dati sacri).

## Diagnosi (verificata, NON ipotizzata)

1. **Non Git LFS**: `.gitattributes` ha `*.png binary !filter`; `git lfs ls-files`
   vuoto; PNG integri (`89504e470d0a1a0a`) in `Modules/Ptv/resources/img/` e
   `public_html/assets/ptv/img/` (story 5.178 aveva già riparato i byte).
2. `curl /admin/login` → **Ignition error page** (~907KB), non la login:
   `ParseError: syntax error, unexpected token "<<"`.
3. Frame: `MetatagData.php:175` = `<<<<<<< .merge_file_PNNkpf` evidenziato;
   `ApplyMetatagToPanelAction:19` (`MetatagData::make()`) →
   `->brandLogo()` mai raggiunto → niente logo, anzi niente pagina.
4. Deploy: sito servito da `/var/www/html/ptvx` (checkout su 10.100.200.15),
   NON dal workspace `_bases`.
5. File su disco già pulito (fix story 5.181, mtime 11:54) ma l'error page era
   ancora servita → **opcache/response stantia**; curl successivo → login reale.

## Root cause

Merge markers `.merge_file_*` (formato `git merge-file` / AI merge tool)
lasciati in `MetatagData.php` nel checkout deployato → ParseError → 500.
Risolto dalla flotta 5.181 (ours `fallbackPublicAssetUrl`, metodo esistente;
theirs `fallbackPublishedAssetUrl` NON esisteva — attenzione con
`resolve-merge-markers.py` che tiene theirs).

## Verifica end-to-end (post-fix)

- `GET /admin/login` → 200, HTML login reale (37KB), cookie `ptv_session`
- Markup: `src="/assets/ptv/img/icon.png"` classi `logo logo-light/dark`
- `GET /assets/ptv/img/icon.png` → 200 `image/png`, 8897B, PNG 536x782 valido
- Pest locale `PtvBrandLogoPngMagicTest`: **1 passed, 4 assertions**

## Insegnamento

Se la risposta di `/admin/login` è un'error page Ignition con
`ParseError: unexpected "<<"`, cercare markers `.merge_file_` nel file del
frame evidenziato — PRIMA di toccare asset/LFS/PNG. Dopo il fix ricurlare:
opcache può servire l'error page stantia.
