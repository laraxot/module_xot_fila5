# 5.181 — `phpstan analyse Modules` fallisce al bootstrap

## Perché

`./vendor/bin/phpstan analyse Modules` non parte: parse error `unexpected <<`
su file PHP con marker `.merge_file_*` residui dopo merge parallelo di due
implementazioni best-effort (story 5.180) e race tra subagent.

## Root cause

Due agenti (e poi swarm IR/Ptv/Rating) scrivevano varianti dello stesso file
senza lock stabile → marker Git in `.php` → PHPStan non carica `Modules/`.

## Fix (union)

1. `AssetAction`: writable guard + `handleCopyFailure`
2. `MetatagData`: solo `fallbackPublicAssetUrl`
3. `AssetActionsTest`: FS reale + reflection best-effort (no mock File leak)
4. Lang `export_xls` it/en: una sola chiave `label` / `plural_label`
5. Test Rating/IR/Ptv: PHPDoc generics + assert sensati (no `assertIsArray` tautologico)
6. Race: `chmod a-w` sui file critici durante il gate finale
