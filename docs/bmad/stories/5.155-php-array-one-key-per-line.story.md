# Story Xot/5.155 — one key per line (sempre)

## Perché

Utente 2026-09-16: *«gli array non li voglio in una sola riga voglio una riga per ogni
chiave, questa regola devi sempre ricordartela»*.

La convenzione esisteva già (`.codestyle-preferences.md`, memoria) ma **non era
enforced**: `SavePhpArrayAction` usava `VarExporter`, che compatta i nested.

## Fix

1. `Modules\Xot\Actions\Arr\SavePhpArrayAction` — exporter custom, una chiave/riga.
2. Wrapper `Array\` / `Arrays\` → delega ad `Arr\`.
3. Pest: nested mai inline.
4. Tool: `bashscripts/tools/expand-lang-arrays-one-key-per-line.php`
5. Expand eseguito: IR, Performance, Progressioni, Ptv, IndennitaCondizioniLavoro
6. Always-on `.cursor/rules/php-array-one-key-per-line.mdc`
7. Pilastro 9 standing order + hook + AGENTS/CLAUDE
