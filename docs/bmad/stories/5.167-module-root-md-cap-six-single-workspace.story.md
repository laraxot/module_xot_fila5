# Story Xot/5.167 — 1 `.code-workspace`, max 6 `.md` nella root di moduli e temi

## Story

Come maintainer della fleet di moduli,
voglio che ogni root `laravel/Modules/<X>/` e `laravel/Themes/<X>/` contenga **uno e un solo**
`.code-workspace` e **al massimo 6** `.md`,
così che IDE, grep, QMD e sync vedano una superficie di package prevedibile.

Istruzione utente 2026-09-24. Riporta il tetto `.md` a 6 (era 5 dalla story 5.158).

## Acceptance Criteria

1. [x] Ogni root ha esattamente 1 `.code-workspace`, chiamato `_<nome-remote>.code-workspace`.
2. [x] Ogni root ha ≤ 6 `.md` (case-insensitive), senza duplicati `CHANGELOG.MD`/`changelog.md`.
3. [x] Nessun contenuto perso: gli `.md` in eccesso vanno in `docs/root-md-files/`.
4. [x] Gate automatico aggiornato (6, e 0 workspace = violazione) + fixer idempotente.
5. [x] Second brain aggiornato (regola, memory, sezione workspace).

## Stato iniziale (20/20 package in violazione)

- Workspace: fino a 5 varianti per root (`_x`, `_module_x`, `_module_x_fila5`, `X`), tutte
  tracciate; `_activity.code-workspace` copiato per errore in Job, UI, User e Xot;
  `_quaeris_fila3` in User. In 8 package mancava del tutto il nome canonico.
- `.md`: Cms 17, Notify 17, Gdpr 13, Activity 12, User 9, UI 7; duplicati case in Cms, Lang,
  UI, User, Xot, Chart, Limesurvey, Quaeris.

## Implementazione

- `bashscripts/tools/fix-module-root-hygiene.py [--apply] [Nome…]`: dry-run di default.
  Workspace: tiene `_<remote>`, altrimenti rinomina la variante più ricca del package; gli
  altri → `git rm`. Md: collassa i duplicati case sul contenuto più ricco; se si supera 6,
  tiene i 5 preferiti + 1 opzionale (ARCHITECTURE › PHILOSOPHY › CONTRIBUTING ›
  GETTING_STARTED › TESTING › SECURITY) e sposta il resto in `docs/root-md-files/<kebab>.md`.
  Se la destinazione contiene già tutte le righe (identica, o con frontmatter in più) cancella
  la copia in root invece di creare un doppione `-N`.
- `audit-module-workspaces.sh`: `MAX_MD=6`, e 0 workspace ora è una violazione.
  `audit-module-root-hygiene.sh`: tetto 6.
- Esecuzione: 68 azioni, secondo run vuoto (idempotente). 12 doppioni `-2` rimossi perché
  già contenuti nella copia in docs. `User/docs/root-md-files/pest-test-report-2.md` tenuto
  perché ha contenuto proprio.

## Verifica

```bash
bash bashscripts/tools/audit-module-workspaces.sh | grep -E 'WORKSPACE|MD-LIMIT'   # vuoto
python3 bashscripts/tools/fix-module-root-hygiene.py                              # piano vuoto
```
