# Story: freccia export nella famiglia xot-files

## Perche'

Richiesta utente su `ExportXlsxAction.php`: "mettere una icona svg migliore,
migliorare anche la ui/ux". L'icona corrente (5.222: foglio+griglia) diceva
"foglio di calcolo" ma **non** "esporta/scarica" — in una toolbar di header
action l'affordance "questo bottone scarica un file" e' il messaggio che
serve. La famiglia (xlsx/xls/pdf) condivide lo stesso linguaggio: il
miglioramento va applicato a tutte e tre per coerenza (AC 5.222).

## Soluzione

Composizione a due cluster dentro lo stesso foglio+piega (base comune):

- **Sinistra — identita' formato** (invariata): header pieno + griglia 2x3
  (xlsx, moderno) | griglia 2 colonne senza header (xls, legacy) | glifo "P"
  (pdf).
- **Destra — azione**: freccia giu' (stem + ali `stroke-linecap=round`),
  stessa semantica di `heroicon-o-document-arrow-down` scelta in 5.220 —
  il dato esce dal file.

Risultato: a 16-24px si leggono entrambi i messaggi: "e' un xlsx" + "lo
scarico". Nessun `<text>`, solo path (regola 5.222).
