## Objective

Reduce root .md clutter across all modules to max 6 files. Reorganize auxiliary docs into semantic subdirs. Enable clarity, maintainability, namespace logic.

## Scope

**Modules affected:**
- Xot: 129 → 6 files (move 123)
- UI: 29 → 6 files
- Cms: 15 → 6 files
- Notify: 13 → 6 files
- Gdpr: 8 → 6 files
- docs: 29 (exempt: central doc hub)

**Root 6-file model (applies all modules):**
1. README.md — module overview, quick start
2. CHANGELOG.md — version history
3. ARCHITECTURE.md — design decisions, internals
4. GETTING_STARTED.md — setup, config
5. TROUBLESHOOTING.md — known issues, FAQ
6. CONTRIBUTING.md — dev workflow, testing

**Subdirectories for overflow:**
- docs/features/ — individual feature docs (cashier.md, cart.md, etc.)
- docs/config/ — configuration guides
- docs/examples/ — code examples, snippets
- docs/archived/ — deprecated, superseded content
