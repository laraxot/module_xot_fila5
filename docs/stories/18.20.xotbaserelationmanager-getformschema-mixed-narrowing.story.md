# Story 18.20 — XotBaseRelationManager: narrowing esplicito su app($class)

## Contesto

`phpstan analyse Modules` (full-tree) segnalava, unico errore reale non
riconducibile al bucket `typeCoverage.constantTypeCoverage`:

```
Xot/app/Filament/Resources/RelationManagers/XotBaseRelationManager.php:110
Cannot call method getFormSchema() on mixed.               method.nonObject
Method ...::getFormSchema() should return array<...> but returns mixed.  return.type
```

## Causa

```php
$instance = app($class);
Assert::isInstanceOf($instance, XotBaseResourceForm::class);
return $instance->getFormSchema();
```

`app($class)` restituisce `mixed` (nessuna narrowing da Larastan, disabilitato
in `phpstan.neon` per decisione owner — vedi
`docs/chat/2026-09-07-phpstan-full-baseline-and-6-modules-fixed.md`).
`Assert::isInstanceOf()` valida a runtime ma non porta un'annotazione
`@phpstan-assert` riconosciuta senza l'estensione dedicata
`phpstan/phpstan-webmozart-assert` (non installata/non attiva qui), quindi
PHPStan non restringe il tipo di `$instance` dopo la chiamata.

## Fix

Aggiunta `/** @var XotBaseResourceForm $instance */` subito dopo l'Assert,
prima del `return`. Nessun `mixed`, nessuna soppressione: il tipo dichiarato
e' esattamente quello gia' garantito a runtime dall'Assert un rigo sopra.

```php
$instance = app($class);
Assert::isInstanceOf($instance, XotBaseResourceForm::class);
/** @var XotBaseResourceForm $instance */
return $instance->getFormSchema();
```
