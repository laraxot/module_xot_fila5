# Epic 5.72 — Filament Resource canonical structure audit

## Understand

### Problem

L'audit filesystem di tutte le Filament Resources rivela che ~100+ risorse mancano
della struttura canonica `Schemas/` e `Tables/`. Gli schema sono inline nei Resource,
in violazione del contratto `XotBaseResource`.

### Perché esiste questo gap

`XotBaseResource` ha un meccanismo di auto-discovery:
- `form(Schema $schema)` cerca `{Resource}Schemas\{Model}Form` → se esiste usa quella
- `table(Table $table)` cerca `{Resource}Tables\{PluralModel}Table` → se esiste usa quella
- Se le classi non esistono, ricade su `getFormSchema()` / `table()` inline del Resource

Il gap esiste perché:
1. Le risorse sono state scritte prima del pattern Schemas/Tables
2. L'auto-discovery rende il fallback funzionante, nascondendo la violazione strutturale
3. Il prompt 06-filament-audit.md non era sufficientemente rigido nel detection

### Root cause detection

Shell audit che ha rivelato il gap:
```bash
for r in Modules/*/app/Filament/Resources/*Resource.php; do
  dir=$(dirname "$r")
  has_inline_form=$(grep -l "function getFormSchema\|function form(" "$r")
  [ -d "$dir/Schemas" ] || echo "MANCANTE Schemas: $r"
  [ -d "$dir/Tables" ] || echo "MANCANTE Tables: $r"
done
```
