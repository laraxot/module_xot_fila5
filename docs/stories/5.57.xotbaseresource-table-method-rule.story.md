# BMAD Story — XotBaseResourceTable / table() Method Rule

## Understand
- XotBaseResourceTable usa il trait HasXotTable (Modules/Xot/app/Filament/Traits/HasXotTable.php)
- HasXotTable definisce `public function table(Table $table): Table` (linea 220)
- Quindi chi estende XotBaseResourceTable NON deve ridefinire `table()`
- Violazione → conflitto di metodo / errore PHPStan / comportamento Filament imprevisibile
