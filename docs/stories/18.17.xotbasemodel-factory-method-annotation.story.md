# BMAD Story — XotBaseModel factory() @method annotation

## Understand
- **Problema**: PHPStan segnala `Call to an undefined static method WorkOrder::factory()` in moduli che usano `WorkOrder::factory()` nelle factory
- **Causa**: XotBaseModel usa `HasXotFactory` trait che definisce `newFactory()` ma non il metodo statico `factory()`
- **Contesto**: WorkOrder estende XotBaseModel, le factory di altri moduli (Intervention, Compliance) chiamano `WorkOrder::factory()`

## Plan
1. Aggiungere `@method` annotation a XotBaseModel per dichiarare `factory()` static method
2. Verificare che PHPStan passi su Intervention e Compliance

## Implement
**File**: `Modules/Xot/app/Models/XotBaseModel.php`

```php
/**
 * @method static \Illuminate\Database\Eloquent\Factories\Factory factory($count = null, $state = [])
 *
 * Class XotBaseModel.
 */
abstract class XotBaseModel extends EloquentModel
{
    use HasXotFactory;
```

## Verify
```bash
./vendor/bin/phpstan analyse Modules/Intervention --memory-limit=4G
./vendor/bin/phpstan analyse Modules/Compliance --memory-limit=4G
```

## Document
- Questa fix risolve l'errore `staticMethod.notFound` per tutti i modelli che estendono XotBaseModel
- Alternativa: usare trait `HasFactory` su ogni modello singolarmente
