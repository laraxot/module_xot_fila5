# Story 18.54 - Restore framework modules from committed merge markers

## Evidence

- Commit `57634f67` ("delete .impeccable/", 1965 files, +106701) committed a working tree
  with unresolved conflicts: 1193 files with `<<<<<<< HEAD` / `>>>>>>> laraxot/dev` in
  `Modules/Xot` (86 app, 42 tests, 28 lang), `Modules/Job` (85 app, 45 tests), `Modules/Lang`,
  `Modules/UI`, plus 667 markdown files, `.gitignore`, `.gitattributes`.
- `php artisan list` failed with a parse error in `Modules/Xot/tests/Support/helpers.php`;
  `XotBaseListRecords` declared the class twice; PHPStan, migrate and Pest were impossible
  for every module.
- Parent commit `6b51736d` (2026-09-04) is clean for 1164 of those files and was the last
  state where `phpstan analyse Modules` passed. No local commit touched the four modules
  between the parent and the import.
- The upstream `laraxot/module_xot_fila5` branch `dev` tip `78c9150f` is itself corrupted
  (200 markers in `app/`). Last clean upstream commits: Xot `f4b8f76a`, Job `654b278`,
  Lang `5fa37543`, UI `ae9cce6d` (all 2026-09-11, cloned in `/tmp/upstream/<module>`).
- The `laraxot/dev` side of `XotBaseResource` declares `final public function getFormSchema()`
  (non static): 77 resources in the repo declare it `public static`, so that side would
  fatal at autoload. The parent side supports both `Schemas/{Model}Form` and the legacy
  static method. The parent side wins for code.

## Resolution policy (mechanical, verifiable)

| File role | Rule |
|---|---|
| Code (`php`, `json`, `xml`, `mdc`, `html`, workspace) | restore the parent revision when it is marker free; otherwise keep the HEAD side block by block |
| `.gitignore`, `.gitattributes` | union of both sides, deduplicated by line |
| Markdown | per block: identical or contained keeps the superset; divergent keeps both sides |
| Generated artifacts (`graphify-out/*`, `.graphify_*`) | removed from git |
| Nested and orphan markers | resolved innermost first; orphan `>>>>>>>` stripped with the preceding `=======` |

Backup of the original files: `/tmp/marker-backup/markers-*.tgz`.
