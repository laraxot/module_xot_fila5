## Analysis

### 1. method.internalClass (3638 = 71%)
- **Causa**: Pest test con `Expectation` methods
- **Soluzione**: Exclude tests in phpstan.neon o fix pattern Pest
- **Azione**: Non blocking per ora

### 2. Cast Errors (513 + 211 + 46 = 770 = 15%)
- **Tipologia**: cast.string, cast.int, cast.double
- **Soluzione**: Narrowing con is_string(), is_numeric()
- **Pattern**: 
```php
is_numeric($v) ? (int) $v : 0
is_string($v) ? $v : ''
is_numeric($v) ? (float) $v : 0.0
```

### 3. Method/Property nonObject (480 + 139 = 619 = 12%)
- **Causa**: Chiamate su mixed o null
- **Soluzione**: instanceof check, null coalescing
- **Pattern**:
```php
if ($obj instanceof Class) { $obj->method(); }
$result = $obj?->method();
```

### 4. staticMethod.notFound (269 = 5%)
- **Causa**: Factory mancanti
- **Soluzione**: Aggiungere HasFactory trait o creare factory
- **Pattern**:
```php
use HasFactory;
// oppure
protected static function newFactory()
```
