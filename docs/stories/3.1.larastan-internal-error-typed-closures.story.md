# Story 3.1 — Larastan Internal Error: Typed Closure Parameters

## Problem

PHPStan/Larastan fails with internal error:
```
Internal error: Call to undefined method 
Larastan\Larastan\Reflection\EloquentBuilderMethodReflection::isForwardedQueryBuilderMethod()
```

Error occurs when analyzing Files containing closure parameters with explicit `Builder` type hints:
```php
fn (Builder $query): Builder => ...
```

## Root Cause Analysis

1. **Version**: Larastan 3.11.0 (latest)
2. **Trigger**: Typed closure parameters in Filament table filter/query closures
3. **Mechanism**: 
   - `EloquentBuilderExtension::isForwardedQueryBuilderMethod()` calls `$methodReflection->getPrototype()->isForwardedQueryBuilderMethod()`
   - When closure has explicit `Builder` type hints, the prototype is NOT an `EloquentBuilderMethodReflection` instance
   - The method `isForwardedQueryBuilderMethod()` exists only on `EloquentBuilderMethodReflection`, not on base `MethodReflection`
   - This causes "Call to undefined method" error

4. **Affected Patterns**:
   ```php
   // BROKEN - causes Larastan internal error
   fn (Builder $wq): Builder => ...
   fn (Builder $q): void => ...
   
   // FIXED - works correctly
   fn ($wq) => ...
   fn ($q) => ...
   ```

## Solution Applied

Removed explicit `Builder` type hints from closure parameters in Filament table/query methods.

### Files Modified

1. **Modules/Intervention/app/Filament/Resources/InterventionResource/Pages/ListInterventions.php**
   - Line 79-84: `searchable(query:)` closure
   - Line 193-196: `Filter::make('has_extra')->query()` closure
   - Line 200-209: `SelectFilter::make('customer_id')->query()` closure
   - Line 213-219: `SelectFilter::make('customer_site_id')->query()` closure
   - Line 235-248: `Filter::make('scheduled_between')->query()` closure

## Search Pattern for Similar Issues

```bash
rg "fn.*Builder.*Builder\|fn \(Builder \$.*\): Builder" Modules --include="*.php"
```

## Prevention

When writing Filament table query/filters:
- DO NOT use explicit `Builder` type hints on closure parameters
- Let PHPStan infer types from context
- The outer method already declares `Builder $query` parameter
