# PHPStan Level 10 monorepo cleanup

**Scope:** Fix 3000+ PHPStan errors across 30+ modules (Activity, AiAssistant, Billing, Catalog, Cms, Comment, Customer, Employee, Geo, Gdpr, Intervention, Lang, Media, Notify, Platform, Progressioni, Rating, Seo, Sigma, Tenant, Thermo, Ui, Wts, Xot, etc.).

**Goal:** Green `phpstan analyse Modules` + baseline Pest coverage per modulo + docs aggiornate.

---

## Context

**Baseline audit (2026-09-06):**
- **Error count:** 3000+ errors (capped at 1000 display; actual 3000+)
- **Distribution by identifier:**
  - `method.internalClass`: 2721 (mostly Pest API false positives; low fix cost)
  - `method.nonObject`: 371 (actual type errors; medium fix cost)
  - `argument.type`: 205 (signature/cast mismatches; medium cost)
  - `staticMethod.notFound`: 189 (method lookup failures; varies)
  - `property.nonObject`: 145 (object access on mixed/null; medium)
  - `cast.string/int/double`: 200+ (narrowing required; low–medium)
  - Other: `offsetAccess`, `return.type`, `method.notFound`, `generics`, etc.

**Bootstrap:** PHPStan loads; no syntax errors in codebase.

**Config:** Immutable `laravel/phpstan.neon` (user-only, no agent modifications).

---

## Phase 1: Audit & Triage (Xot lead)

Per-module scan to identify:
1. **Count by error type** (method.internalClass vs real bugs)
2. **Complexity bracket:** high (refactor-heavy) vs low (cast narrowing)
3. **Module size impact:** errors/LOC ratio
4. **Blockers:** missing types, unstable vendor APIs

**Deliverable:** Triage matrix in `Modules/Xot/docs/phpstan-l10-triage.md`:
| Module | Total | method.internalClass | argument.type | cast.* | Complexity | Assignment |
|--------|-------|----------------------|---------------|--------|------------|------------|

## Phase 2: Parallel Fix Agents (per-module owners)

Each module with **100+ errors** → dedicated fix agent:
- Fix pattern: narrow types, add `@property` docs, remove casts, add unions
- Gate per module: `phpstan analyse Modules/<Mod> --no-progress` green
- Coverage baseline: `Pest --coverage` before/after, track delta in `docs/coverage.md`
- Docs update: `docs/` in modulo (if behavior changed)
- Git sync: `git fetch + merge + add/commit/push` per modulo

**Modules with 100+:**
- AiAssistant

- Xot
- (others TBD after audit)

## Phase 3: Re-gate & Verification (Xot)

After all modules return green:
1. Full `phpstan analyse Modules` → zero errors (or only unmatched ignore comments)
2. Pest suite → coverage ≥ baseline (no regression)
3. PHPMD/PHPInsights → no new violations
4. Docs consolidated in `Modules/<Mod>/docs/` (no orphan BMAD drafts in root)
5. All modules sync'd: `git log --oneline` shows commit from agent

## Notes

- **No neon edits** — agent must NOT modify phpstan.neon; user-only.
- **`mixed` → union/narrowing** — never leave cast to silence analyzer.
- **Pest false positives** (@property-read on `Expectation<TValue>`): ignore inline only, with identifier.
- **Test files excluded** — phpstan.neon: `excludePaths: ./*/tests/*` applies globally; no re-analyze test-only files.
- **Lock discipline** — `lock.sh` before edit, `unlock.sh` after gate passes.
