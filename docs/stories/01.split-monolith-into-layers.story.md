# Scindere Xot Monolith in 5 Moduli Stratificati

## Obiettivo

Spezzare Xot (44K LOC, 2.077 import cross-modulo) in 5 moduli indipendenti per layer. Ridurre coupling critico, abilitare refactoring su 45+ moduli dipendenti.

**Impatto:** -9.5x hub risk, zero breaking changes per consumer modules.

## Contesto

**Problema:**
- Xot è unico punto di failure: ogni modulo dipende
- 44K LOC mescola concerns: trait, base class, UI scaffold, utility, config
- Cambio a XotBaseResource ripple a 45+ moduli
- Circular dependencies bloccano refactoring

**Soluzione:**
Scindere in 5 moduli per layer, ciascuno indipendente:

1. **XotCore** — base class, convention discovery
2. **XotPersistence** — model trait, migration
3. **XotUI** — form/table builder, Filament pattern
4. **XotUtility** — helper, file handling
5. **XotConfig** — metadata, feature flag

Ogni modulo dipende da XotCore; XotCore dipende da nulla dominio.

### Week 1: Setup & XotCore

1. Crea `Modules/XotCore/` (git, composer, namespace)

4. Crea XotCoreServiceProvider


1. Crea `XotPersistence` con model, factory, migration

3. Test dipendenze: XotUI import XotPersistence, funziona

1. Crea `XotUtility` con helper, file handler
2. Crea `XotConfig` con feature flag, metadata

### Week 4: Integration & Testing

1. Verifica 45+ consumer import da Xot (con re-export), funzionano
2. PHPStan L10 su 6 moduli
3. Test suite completo su tutti moduli
4. Commit + push su ciascun nuovo modulo + Xot refactor

## Metrica & Success

|---------|--------|-------|------|
| Xot imports | 2.077 | ~500 | 76% reduction |
| Max imports (XotCore) | - | ~50 | minimal hub |
| Circular deps | 10 | 0 (hopefully) | eliminated |
| LOC per modulo | 44K | 8-10K (avg) | balanced |
| PHPStan coverage | 69% | 85%+ | improved |

## Risk & Mitigation

| Risk | Mitigation |
|------|-----------|
| Breaking consumer imports | Xot re-export tutti 5 moduli (backward compat) |
| Circular deps durante split | Design dependency DAG prima: Core → Persistence → UI |
| Test coverage drop | Test in isolamento; integration test consumer |
| Git workflow (5 moduli + Xot) | Parallel commits; coordina pull+push |
