# XOT-5.48 — PHPStan: fix reali, zero ignore stale

## Story

Come **tech lead quality**, voglio che gli errori PHPStan siano risolti nel codice e non
mascherati da `@phpstan-ignore` obsoleti o da PHPDoc `@return` troppo stretti su `casts()`,
così il gate misura debito reale.

## Problema rilevato

Con `reportUnmatchedIgnoredErrors: false` nel neon, il CLI segnalava **0 errori** mentre
con analisi rigorosa comparivano **51** issue (47 ignore stale + 4 `return.type` su `casts()`).

## Fix applicati (solo codice)

1. **`casts()` + `array_merge(parent::casts())`**: rimosso `@return array<string, string>` stretto (9 file moduli)
2. **Media tests**: rimossi ~47 `@phpstan-ignore-next-line` stale (nessun errore sottostante)
3. **Gdpr `PestHelpers`**: pattern `TestCase::$currentTest` (come Cms) — niente `HigherOrderTapProxy` / ignore

## Acceptance Criteria

1. [x] Nessun `*.neon` toccato dall’agente
2. [x] `./vendor/bin/phpstan analyse Modules` → 0 errori
3. [x] Nessun `@phpstan-ignore` stale nei file bonificati
4. [x] `phpstan-status.md` aggiornato con nota gate rigoroso

## File toccati

- `Modules/*/app/Models/BaseModel.php` (Geo, Notify, Job, Activity, …)
- `Modules/TechPlanner/app/Models/Event.php`, `PhoneCall.php`
- `Modules/Media/tests/**` (ignore rimossi)
- `Modules/Gdpr/tests/PestHelpers.php`, `TestCase.php`
