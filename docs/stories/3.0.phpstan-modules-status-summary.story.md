### 1. Pest Mixin Methods (296 errors)
- `method.internalClass` - Using `->toBe()`, `->toBeEmpty()`, etc. directly
- **Solution**: Use `expect($value)->toBe()` pattern

### 2. Cast Mixed (multiple modules)
- `cast.string` - Cannot cast mixed to string
- `cast.int` - Cannot cast mixed to int
- **Solution**: Add type checks before cast

### 3. Argument Type Mismatches
- Various function parameter type errors
- **Solution**: Add proper type checking or casting
