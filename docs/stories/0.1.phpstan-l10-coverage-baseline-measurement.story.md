## Summary

Establish baseline coverage metrics BEFORE Epic 6 dev work begins. After all stories complete, measure again to verify coverage↑.

**Why:** Standing order requires coverage to increase, not maintain. Need baseline to prove delta.

## Problem

- No current coverage.md files exist in most modules
- Cannot verify "coverage ↑" claim without baseline
- No automated measurement = manual verification only

## Solution

**Phase 1: Baseline Measurement (Before dev)**
1. For each module: run `./vendor/bin/pest --coverage`
2. Capture coverage % (lines/methods/functions)
3. Create/update `Modules/<Mod>/docs/coverage.md` with baseline
4. Git commit baseline

**Phase 2: After-Dev Measurement (After all stories)**
1. Re-run coverage for all modules
2. Update coverage.md with new %
3. Calculate delta (must be ≥0, ideally ≥1%)
4. Document in git commit

## AC

1. ✅ Identify which modules need coverage.md
2. ✅ Run pest --coverage for each module (before dev)
3. ✅ Create coverage.md baseline files
4. ✅ Commit baseline state
5. ✅ After all Epic 6 stories complete: re-run coverage
6. ✅ Update coverage.md with new metrics
7. ✅ Verify all deltas positive
