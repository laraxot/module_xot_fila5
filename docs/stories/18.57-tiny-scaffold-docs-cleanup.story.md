## Contesto

Ricognizione repo-wide (fork parallela, stessa sessione) ha trovato 814 file `.md` in
`Modules/Xot/docs/` con meno di 5 righe. Questa story copre la prima fase: i file
riconducibili a cartelle già dichiarate anti-pattern dalla policy del modulo.

## Scoperta chiave

`docs/no-ai-tool-scaffold-dirs.md` (2026-07-16) documenta **esattamente** questo pattern
e prescrive la regola "boy scout": cancellare `docs/**/archive/`, `docs/**/legacy/` e
scaffold simili, non consolidarli — "Git è l'archivio, non una cartella `archive/`
parallela".

Le cartelle `_archive/`, `_integration/`, `legacy/`, `raw/root-import/`, `root-md-files/`
combaciano con l'anti-pattern descritto. Verificato overlap fra coppie di cartelle:
`legacy/` vs `raw/root-import/` = 125/126 file identici; `_integration/` vs
`root-md-files/` = 45/105 identici — stesso import fatto più volte da script diversi.

## Lavoro svolto (questa story)

- Identificati 337 file tiny (<5 righe) dentro le 5 cartelle anti-pattern confermate
- Verificato: nessun file nel resto di `docs/` referenzia il path esatto di questi file
  (solo riferimenti generici alle policy che *descrivono* le cartelle, non ai singoli file)
- Rimossi 7 file aggiuntivi a 0 byte in `docs/old_tasks/` (report phpstan storici, non
  referenziati per path esatto)
- Commit `fd84e736`: 205 file tracciati rimossi (142 righe di contenuto totale — conferma
  che erano sostanzialmente vuoti), + 139 file untracked mai committati rimossi dal
  working tree senza produrre diff

## Fuori scope — follow-up necessario (story separata)

**470 file rimangono non toccati**, fuori dalle 5 cartelle anti-pattern:
- 274 file direttamente in `docs/` (non sottocartelle) — include un cluster massiccio di
  duplicati: `xotbase-extension-rules` esiste in **16 varianti** fra `docs/`,
  `docs/historical/`, `docs/wiki/consolidated/` (UPPERCASE, snake_case, kebab-case, `-1`,
  `-2`, `-variant`, `-conflict`, `-comprehensive`) — sintomo dello stesso script di
  consolidamento fallito descritto in `no-ai-tool-scaffold-dirs.md`, mai risolto per questo
  cluster specifico
- 99 file con contenuto ma senza newline finale (falsi "0 righe" per `wc -l`)
- 371 file con 1-4 righe di contenuto reale (bookmark/link salvati, non scaffold vuoto)

Questi richiedono, per ogni cluster di varianti duplicate: identificare la versione "viva"
(più recente/più completa, tipicamente in `docs/wiki/consolidated/`), verificare che il
contenuto sia effettivamente incluso, poi rimuovere le varianti — non un'eliminazione
automatica sicura come per gli scaffold vuoti.
