# BMAD Story — Improve and execute quality-gates prompt

## Understand

Il prompt `03-quality-gates.md` descrive un processo di qualità multi-gate (Pint → PHPStan → Pest → PHPMD → PHPInsights) per garantire che tutti i moduli siano conformi alle specifiche di qualità. Il problema è che il prompt originale non è sufficientemente chiaro sui requisiti di esecuzione e verifica, e non specifica come gestire i conflitti tra agenti multipli.

Applicabili regole:
- **Neon immutabile**: `laravel/phpstan.neon` non deve essere modificato da nessun agente.
- **Lock per file**: ogni edit deve essere bloccato con `bashscripts/lock/` prima della modifica.
- **Sequenza di gate**: php -l → phpstan → phpmd → phpinsights → pest.
- **Scope multi-agente**: correggere solo i file dichiarati nell'owned_scope.
- **Evidenza**: output dei comandi deve essere verificato.

## Plan

1. **Creare la story BMAD** con il template appropriato.
2. **Analizzare il prompt attuale** (`03-quality-gates.md`) per identificare lacune.
3. **Definire i file propri** da modificare (nel contesto dei moduli `Modules`).
4. **Eseguire i gate** su ciascun modulo per verificare che il prompt funzioni.
5. **Documentare** le modifiche necessarie nei file e aggiornare la story.

## Implement

- Creare la story BMAD con il template standard.
- Eseguire `php -l` su tutti i file PHP modificati.
- Eseguire `phpstan analyse Modules --no-progress --memory-limit=-1` su ogni modulo.
- Eseguire `tools/phpmd.sh <file> text phpmd.xml` su ogni modulo.
- Eseguire `tools/phpinsights.sh analyse <file>` su ogni modulo.
- Eseguire `vendor/bin/pest` per verificare che i test passino.
- Aggiornare la story con i risultati ottenuti.
