# BMAD Story — PHPMD Fixes Campaign

## Understand
- **Obiettivo**: Risoluzione issues PHPMD
- **Strumento**: `./tools/phpmd.sh`
- **Regole**: naming, design, unusedcode, controversial

## Plan
1. Eseguire PHPMD su tutti i moduli
2. Categorizzare issue per tipo
3. Fix sistematici
4. Verificare e git sync

## Implement

### Step 1: PHPMD su tutti i moduli
```bash
./tools/phpmd.sh Modules text controversial,naming,design,unusedcode 2>&1 | grep -v "^#" | head -100
```

### Step 2: Categorizzazione
- **Naming**: variabili/metodi non in camelCase
- **ShortVariable**: variabili con nome < 3 caratteri
- **UnusedCode**: metodi/parametri non usati
- **Design**: complessità ciclomatica

### Step 3: Fix Pattern
```php
// ❌ Short variable
$v = $row->id;

// ✅ CamelCase
$variable = $row->id;

// ❌ Unused parameter
function foo($unused) {}

// ✅ Remove or use
function foo() {}
```
