# XOT-5.50 — ide-helper:models senza errori team/Comune

## Story

Come dev, voglio `php artisan ide-helper:models` (default `--nowrite`) senza errori
Spatie `TeamModelNotConfigured` né crash Sushi su `Comune`, così PHPDoc modelli resta completo.

## Problema

1. **teams()**: overlay `config/*/permission.php` tenant senza `models.team` → registrar null durante ide-helper
2. **Comune Sushi**: insert multi-row con colonne disallineate se righe JSON incomplete

## Fix

1. Aggiungere `'team' => Team::class` in tutti i `permission.php` tenant (allineati al root)
2. `UserServiceProvider::boot()` → sync `PermissionRegistrar::setTeamClass()` da config
3. `Comune::getRows()` — righe uniformi per Sushi (stesse chiavi, ordine ksort)

## Acceptance Criteria

1. [x] `php artisan ide-helper:models --nowrite --no-interaction` senza errori team/Comune
2. [x] Dati `comuni.json` intatti (sacri)
3. [x] Nessun touch `phpstan.neon`
