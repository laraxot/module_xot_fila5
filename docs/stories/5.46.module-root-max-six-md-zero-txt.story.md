# XOT-5.46 — Root moduli: zero `.txt`, max 6 `.md`

## Story

Come **manutentore monorepo**, voglio che ogni root `laravel/Modules/<Name>/` non contenga
file `.txt` e al massimo **6** file `.md`, con un gate bash verificabile, così audit, QMD e
agenti non preloadano rumore di sessione.

## Perché

La root è il **contratto nwidart** visibile a CI e submodule sync. Appunti `.txt`, test di
sync e duplicati `CHANGELOG.MD`/`CHANGELOG.md` sporcano grep, graphify e second brain.
La policy precedente (max 4 o max 5) era troppo restrittiva per stub `AGENTS.md`/`CLAUDE.md`
e overview tipo `ARCHITECTURE.md`; **6** è il tetto operativo richiesto dal tech lead.

## Regole (scope: solo root modulo, `-maxdepth 1`)

| Tipo | Limite |
|------|--------|
| `*.txt` | **0** — spostare in `docs/root-txt-files/` o eliminare |
| `*.md` (case-insensitive) | **max 6** — preferiti: `README.md`, `CHANGELOG.md`, `LICENSE.md`, `AGENTS.md`, `CLAUDE.md`, +1 opzionale |
| Duplicati case | **vietati** (`CHANGELOG.md` + `CHANGELOG.MD` → tenere uno solo) |
| Altro `.md` | → `docs/root-md-files/` (kebab-case) o `docs/wiki/` |

## Acceptance Criteria

1. [x] `bash bashscripts/tools/audit-module-root-hygiene.sh` → exit `0` su tutti i moduli
2. [x] Zero `.txt` in root di ogni modulo
3. [x] ≤6 `.md` per modulo; duplicati case-insensitive assenti
4. [x] Second brain aggiornato: `module-theme-root-md-files-limit.md`, memory, trigger map
5. [x] Bonifica: Lang/Xot `CHANGELOG.MD`, Notify `whatsapp.md`, Geo `AGENT_GUIDE.md`, Seo test junk, Job `ARCHITECTURE.md` duplicato
