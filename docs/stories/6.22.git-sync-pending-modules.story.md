## Plan
1. Per ogni modulo: fetch + merge + add + commit + push
2. Verificare che non ci siano conflitti

## Workflow
```bash
cd Modules/<Module>

# 1. Fetch
git fetch laraxot dev

# 2. Merge
git merge laraxot/dev --allow-unrelated-histories -s resolve

# 3. Add
git add -A

# 4. Commit
git commit -m "chore(<module>): sync pending changes"

# 5. Push
git push -u laraxot dev
```
