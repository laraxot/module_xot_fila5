## Architecture Constraint

**`XotBaseResource` does NOT use `HasXotTable` directly.** It delegates `table()` to `XotBaseResourceTable::configure()`, which uses `HasXotTable`. Concrete resources extending `XotBaseResource` must NOT add `use HasXotTable`.

## Method signatures (final)

```php
/**
 * Get the column name used for table reordering.
 * Returns 'order_column' if it exists in the model's table, null otherwise.
 * Override in subclass to use a different column name.
 */
protected function getOrderColumn(): ?string
{
    $model = $this->getModel();
    $schema = $model->getConnection()->getSchemaBuilder();

    return $schema->hasColumn($model->getTable(), 'order_column')
        ? 'order_column'
        : null;
}
```

### Update table() method

Add after `resolveTable()`:

// Auto-enable reordering if order column exists
