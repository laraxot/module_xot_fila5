# BMAD Story — PHPStan Method NonObject Fix Pattern

## Understand
- **Errore**: `method.nonObject` - 480 occorrenze
- **Causa**: Chiamate a metodi su oggetti che PHPStan non riconosce come oggetti (mixed, null, etc.)
- **Soluzione**: instanceof check o null-safe operator

## Pattern Library

### Pattern 1: instanceof Check
```php
// ❌ Errato
$obj->method();

// ✅ Corretto
if ($obj instanceof SomeClass) {
    $obj->method();
}
```

### Pattern 2: Null-safe Operator
```php
// ❌ Errato
$result = $obj->method();

// ✅ Corretto
$result = $obj?->method();
```

### Pattern 3: Null Coalescing with Default
```php
// ❌ Errato
$result = $obj->method();

// ✅ Corretto
$result = $obj?->method() ?? defaultValue;
```

### Pattern 4: Early Return
```php
// ❌ Errato
if ($condition) {
    $obj->method();
}

// ✅ Corretto
if (! $obj instanceof SomeClass) {
    return;
}
$obj->method();
```

## Usage Examples

### Query Builder Results
```php
// Risultato può essere null
$record = DB::table('users')->first();

// ❌ Errato
$name = $record->name;

// ✅ Corretto
$name = $record?->name ?? '';
```

### Model Relationships
```php
// Relazione può essere null
$user = $post->author;

// ❌ Errato
$email = $user->email;

// ✅ Corretto
$email = $user?->email ?? '';
```

### Collection Items
```php
// Item può essere null
$item = $collection->first();

// ❌ Errato
$item->method();

// ✅ Corretto
$item?->method();
```
