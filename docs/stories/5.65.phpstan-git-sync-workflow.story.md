# BMAD Story — Git Sync Workflow

## Understand
- **Problema**: Multipli moduli con repo git separati, necessità di sync
- **Regola**: Mai push --force; git only forward

## Workflow
```bash
# 1. Fetch upstream
git fetch laraxot dev

# 2. Merge con strategia resolve
git merge laraxot/dev --allow-unrelated-histories -s resolve

# 3. Add e commit modifiche locali
git add -A
git commit -m "fix(<modulo>): <descrizione>"

# 4. Push
git push -u laraxot dev
```

## Risoluzione Conflitti
```bash
# Se conflitti durante merge
git checkout --theirs <file>
git add <file>
git commit
```
