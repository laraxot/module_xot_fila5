# BMAD Story — PHPStan Mixed Type Narrowing Patterns

## Understand
- **Problema**: Errori PHPStan per cast da `mixed` a tipi primitivi
- **Soluzione**: Usare narrowing con funzioni built-in PHP prima del cast
- **Regola**: Mai cast diretto su mixed

## Pattern Library

### Integer Cast
```php
// ❌ Errato
$int = (int) $mixedVar;

// ✅ Corretto
$int = is_numeric($mixedVar) ? (int) $mixedVar : 0;
```

### String Cast
```php
// ❌ Errato
$string = (string) $mixedVar;

// ✅ Corretto
$string = is_string($mixedVar) ? $mixedVar : '';
```

### Float Cast
```php
// ❌ Errato
$float = (float) $mixedVar;

// ✅ Corretto
$float = is_numeric($mixedVar) ? (float) $mixedVar : 0.0;
```

### Boolean Cast
```php
// ❌ Errato
$bool = (bool) $mixedVar;

// ✅ Corretto
$bool = is_bool($mixedVar) ? $mixedVar : false;
```

### Array Cast
```php
// ❌ Errato
$array = (array) $mixedVar;

// ✅ Corretto
$array = is_array($mixedVar) ? $mixedVar : [];
```

## Usage in Laravel

### Query Builder Results
```php
// Risultato DB stdClass
$row = DB::table('users')->first();

// ❌ Errato
$id = (int) $row->id;

// ✅ Corretto
$id = is_numeric($row->id ?? null) ? (int) $row->id : 0;
```

### Form Data
```php
// ❌ Errato
$id = (int) $data['id'];

// ✅ Corretto
$id = is_numeric($data['id'] ?? null) ? (int) $data['id'] : 0;
```

### Collection Map
```php
// ❌ Errato
->map(fn ($row) => (int) $row->id)

// ✅ Corretto
->map(fn ($row) => is_numeric($row->id ?? null) ? (int) $row->id : 0)
```
