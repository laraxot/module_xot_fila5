# XOT-17.14 — bonifica dei 443 errori di `phpstan analyse Modules`

## Story

Come **maintainer del monorepo**, voglio **portare `cd laravel &&
./vendor/bin/phpstan analyse Modules` a zero errori senza toccare
`phpstan.neon`**, così **che il gate PHPStan del prompt 03 torni verde e i
falsi negativi non nascondano difetti reali**.

## Misura di partenza (2026-08-27)

`build/phpstan-full-qwen.json`: **443 errori in 86 file**.

Per identifier (top): 90 `method.nonObject`, 54 `method.notFound`,
38 `theCodingMachineSafe.function`, 30 `cast.string`, 30 `argument.type`,
28 `pest.expectation.redundant`, 23 `class.notFound`,
18 `typeCoverage.constantTypeCoverage`.

Per modulo: Xot 274, Employee 39, Seo 34, Notify 28, Media 20, Lang 16,
Job 11, User 6, Geo 5, UI 5, Activity 2, TechPlanner 2, Cms 1.

File peggiori: `Xot/tests/Unit/Actions/Cast/SafeEloquentCastActionTest.php` (36),
`Xot/tests/Feature/FixStructureTest.php` (34) **e il suo duplicato minuscolo**
`fixstructuretest.pest.php` (21) — il minuscolo è il condannato (regola
multi-sessione n. 5 del prompt 03).

## Vincoli (non negoziabili)

- `laravel/phpstan.neon` è dell'utente: mai modificarlo, mai `-c`, mai altri
  `.neon`, mai baseline generate dall'agente.
- Gli errori si risolvono nel codice; unica eccezione i falsi positivi Pest
  `method.internalClass` con `@phpstan-ignore` inline (identifier + motivo).
- `mixed` ultima spiaggia; prima narrowing, union types, generics.
- Git forward-only: niente revert/reset; i test sono artefatti permanenti.
- File WIP di altre sessioni non si toccano se non pertinenti al cluster.

## Acceptance Criteria

1. `cd laravel && ./vendor/bin/phpstan analyse Modules` → 0 errori (o delta
   documentato con motivo per ogni residuo).
2. `phpstan.neon` non modificato, nessun nuovo `.neon`, nessuna baseline.
3. Il duplicato `fixstructuretest.pest.php` è rimosso o riconciliato col
   file PascalCase, con nota in `docs/chat/`.
4. Nessun nuovo `mixed` nelle firme; nessun `@phpstan-ignore` fuori
   dall'eccezione Pest.
5. La suite Pest dei moduli toccati resta verde (o blocco d'ambiente
   documentato con exit 3).
