# BMAD Story — Fix GetComponentsAction JSON Decode Bootstrap Error

## Understand
- **Problema**: PHPStan bootstrap fallisce con `Safe\Exceptions\JsonException` in `GetComponentsAction.php:54`
- **Causa**: `_components.json` ha conflitti di merge git non risolti + `json_decode` senza `JSON_THROW_ON_ERROR`
- **Regole**: `phpstan.neon` non si modifica; `mixed` sostituito con tipi opportuni; `User` -> `UserContract` / `XotData`

## Plan

3. Verifica bootstrap PHPStan
4. Esegui phpstan + phpmd + phpinsights + pest
5. Commit modifiche
