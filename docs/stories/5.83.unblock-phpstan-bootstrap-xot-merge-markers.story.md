`php -l` pulito su ognuno, poi bootstrap PHPStan verde, poi riprendere 5.79 (segnalazioni
PHPStan reali).

indovinare. `php -l` dopo ogni file. Nessun `git revert`/`checkout`/reset — solo edit
chirurgico + verifica sintattica. Commit unico a fine swarm (non uno per agente, per non
