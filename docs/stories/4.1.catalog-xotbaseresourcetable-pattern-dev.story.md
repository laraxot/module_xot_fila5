## Summary

Story 4.1 planning document created (planning agent). This is dev execution story.

**Issue:** 6 Catalog Resources override `table()` method, violating Liskov Substitution Principle (LSP).

**Rule:** Resources extending XotBaseResourceTable must NOT override table(). Base class provides implementation; subclasses delegate.

## Problem

```
Modules/Catalog/app/Filament/Resources/*/php:

CatalogFrequencyResource extends XotBaseResourceTable
  - has table() override ❌ violates LSP

CatalogMeasureUnitResource extends XotBaseResourceTable
  - has table() override ❌

CatalogModelResource, CatalogPartTypeResource, MetelCatalogResource, ProductResource
  - same violation ❌
```

## Solution (from planning story 4.1)

1. Remove `table()` override from all 6 Resources
2. Create new `*Resource/Tables/*Table.php` classes (one per Resource)
3. Move table-specific logic to dedicated Table classes
4. Update Resource to reference Table class
5. Document pattern in `docs/filament-table-architecture.md`
