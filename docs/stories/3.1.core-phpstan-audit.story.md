## Workflow

1. **Run single-module scan** (post-Cms fix):
   ```bash
   phpstan analyse Modules/Xot --no-progress
   ```

2. **Catalog errors** by type:
   - Parse errors
   - Type coverage (const, param, return)
   - Deprecated API
   - Mixed types
   - Class not found

3. **Create sub-stories** per error category:
   - `3.1.1` — Type declarations
   - `3.1.2` — Deprecated methods
   - `3.1.3` — Mixed type narrowing
   - etc.

4. **Fix in dependency order**:
   - Base contracts/interfaces first
   - Then implementations
   - Then consumers (if in same module)

5. **Verify**:
   ```bash
   phpstan analyse Modules/Xot --no-progress
   pest Modules/Xot/tests -c Modules/Xot/phpunit.xml --no-coverage
   ```

6. **Git sync**:
   - Fetch laraxot/dev, merge
   - Commit, push

## Success Criteria

- PHPStan: 0 errors on `Modules/Xot`
