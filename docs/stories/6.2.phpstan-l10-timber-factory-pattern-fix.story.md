## Summary

Timber module: ~300 PHPStan L10 errors. Root causes:
1. Factory return type not resolved (Larastan generics from trait @use)
2. Static methods on model not found by PHPStan
3. Mixed type in query builders (seeders, tests)

## Problem

```
Timber/database/seeders/*Seeder.php:
  Call to undefined static method Timber*::factory()
  🪪  staticMethod.notFound

Timber/Filament/Resources/*/Tables:
  Cannot call method where() on mixed
  🪪  method.nonObject
```

## Solution

Apply factory type narrowing pattern (same as Wts story 3.1):
1. Create `Tests/Expectations/TimberTestCase` static helper
2. Define `static createTimberUnit(): TimberUnit` (returns concrete type)
3. Replace all `TimberUnit::factory()->create()` with `TimberTestCase::createTimberUnit()`
4. Update seeders + tests
