# 18.1: README dei moduli agnostici, specifici e con badge calcolati

**Story ID:** 18.1
**Epic:** 18 — Vetrina dei moduli
**Slug:** module-readme-agnostic-computed-badges
**Status:** in-progress
**Created:** 2026-09-03
**Updated:** 2026-09-03

## Story

Come maintainer della famiglia Laraxot voglio che il `README.md` nella root di ogni modulo (e quello di `laravel/`) racconti quel modulo nel dettaglio, con badge e numeri calcolati e non scritti a mano, senza alcun riferimento a progetti host, così che ogni modulo sia una vetrina onesta e riusabile in qualsiasi progetto.

## Contesto misurato (2026-09-03)

- 48 moduli con `composer.json` in `laravel/Modules`; 16 con repository GitHub pubblica, 29 privata, 3 senza `.git` proprio (Blog, Comment, TimberBilling).
- 44 README su 45 citavano `Platform-FixCity`, progetto estraneo. Il maintainer ha confermato: moduli e temi sono agnostici; FixCity e Techplanner non c'entrano.
- Badge statici errati: `Laravel 12` (composer.lock: 13.30.1), `Filament 5` senza patch, `PHPStan Level 10` (phpstan.neon: `max`).
- Un processo concorrente (`opencode`) ha riscritto tutti i README con template identico e badge GitHub per repo private (immagini rotte). Similarità media tra README misurata: 0,656 (913 coppie su 1128 oltre soglia 0,35).
- `laravel/CLAUDE.md` (sezione Laravel Boost) dichiara versioni stantie (Laravel 12, Filament 4, PHP 8.3): non è fonte di verità per i badge.

## Acceptance criteria

1. Ogni `laravel/Modules/<Nome>/README.md` ha i tre blocchi marker `laraxot:badges`, `laraxot:metrics`, `laraxot:docs` riempiti da `bashscripts/tools/readme/module-readme-badges.sh`; nessun badge scritto a mano.
2. `bash bashscripts/tools/readme/module-readme-badges.sh --host --check` esce 0: nessun README stantio, senza marker o contenente `FixCity|fixcity|base_workorder_fila5`.
3. `python3 bashscripts/tools/readme/module-readme-similarity.py` esce 0 con soglia 0,35: la prosa è specifica per modulo.
4. Ogni README contiene le sezioni richieste dal maintainer: perché esiste, logica, visione, scopo, politica, religione, filosofia, zen, con contenuto ricavato dal codice del modulo (modelli, relazioni, firme delle Actions, pagine, config, test).
5. `laravel/README.md` descrive il progetto host con badge calcolati e tabella dei moduli calcolata (`laraxot:host-badges`, `laraxot:modules`).
6. Nessun link relativo rotto nei README.
7. Commit e push nel repository di ogni modulo toccato e nel repository root.
