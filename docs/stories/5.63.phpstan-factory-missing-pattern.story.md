# BMAD Story — PHPStan Factory Missing Pattern

## Understand
- **Problema**: PHPStan segnala `Call to an undefined static method ::factory()`
- **Causa**: Modello senza trait `HasFactory` o factory non definita
- **Soluzione**: Aggiungere `HasFactory` trait o creare factory

## Pattern 1: Add HasFactory Trait
```php
<?php

namespace Modules\Blog\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
use Modules\Xot\Models\XotBaseModel;

class Post extends XotBaseModel
{
    use HasFactory;
    // ...
}
```

## Pattern 2: Create Factory
```php
<?php

namespace Modules\Blog\Database\Factories;

use Illuminate\Database\Eloquent\Factories\Factory;
use Modules\Blog\Models\Post;

class PostFactory extends Factory
{
    protected $model = Post::class;

    public function definition(): array
    {
        return [
            'title' => fake()->sentence(),
            'content' => fake()->paragraphs(3, true),
        ];
    }
}
```

## Pattern 3: Register in Model
```php
<?php

namespace Modules\Blog\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Factories\Factory;
use Modules\Blog\Database\Factories\PostFactory;
use Modules\Xot\Models\XotBaseModel;

class Post extends XotBaseModel
{
    use HasFactory;

    protected static function newFactory(): Factory
    {
        return PostFactory::new();
    }
}
```

## Verify
```bash
./vendor/bin/phpstan analyse Modules/<Module> --error-format=table 2>&1 | grep "factory"
```
