# BMAD Story — PHPStan StaticMethod NotFound Fix Pattern

## Understand
- **Errore**: `staticMethod.notFound` - 269 occorrenze
- **Causa**: Chiamate a metodi statici non definiti (es. factory)
- **Soluzione**: Aggiungere HasFactory trait o definire metodo statico

## Pattern Library

### Pattern 1: Add HasFactory Trait
```php
// In Model
use Illuminate\Database\Eloquent\Factories\HasFactory;

class Post extends Model
{
    use HasFactory;
}
```

### Pattern 2: Define Custom Factory Method
```php
// In Model
use Illuminate\Database\Eloquent\Factories\Factory;

class Post extends Model
{
    protected static function newFactory(): Factory
    {
        return PostFactory::new();
    }
}
```

### Pattern 3: Check Class Exists Before Call
```php
// ❌ Errato
Post::factory()->create();

// ✅ Corretto
if (class_exists(PostFactory::class)) {
    Post::factory()->create();
}
```

### Pattern 4: Method Exists Check
```php
// ❌ Errato
Model::someStaticMethod();

// ✅ Corretto
if (method_exists(Model::class, 'someStaticMethod')) {
    Model::someStaticMethod();
}
```
