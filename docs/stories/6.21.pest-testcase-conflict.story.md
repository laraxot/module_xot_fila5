# BMAD Story — Pest Test Case Conflict Resolution

## Understand
- **Problema**: `Test case [Modules\AI\Tests\TestCase] can not be used` - duplicazione
- **Causa**: Più file usano lo stesso test case in moduli con struttura non standard
- **Regola**: Un modulo = un TestCase, ogni file = un describe/it block

## Error
```
Test case [Modules\AI\Tests\TestCase] can not be used. 
The folder [/var/www/_bases/base_workorder_fila5/laravel/Modules/AI/tests/Unit/Actions/ContextCompressorActionTest.php] 
already uses the test case [Modules\AI\Tests\TestCase].
```

## Plan
1. Identificare tutti i moduli con problemi di test case
2. Verificare struttura tests/ di ogni modulo
3. Sistemare Pest.php per load corretto
4. Verificare che pest run passi

## Implement

### Step 1: Test Pest configuration
```bash
./vendor/bin/pest --filter="TestCase" 2>&1 | grep "can not be used"
```

### Step 2: Verifica struttura tests/
```bash
ls Modules/*/tests/
```

### Step 3: Fix Pest.php
Il problema è che ogni modulo ha il proprio Pest.php che definisce un test case diverso.

Soluzione: in `tests/Pest.php` root, caricare solo i moduli con Pest.php custom.
