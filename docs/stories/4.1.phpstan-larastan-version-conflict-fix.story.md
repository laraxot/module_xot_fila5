## Dev Notes

**Error Details:**
```
Internal error: Call to undefined method Larastan\Larastan\Reflection\EloquentBuilderMethodReflection::isForwardedQueryBuilderMethod() 
while analysing file /var/www/_bases/base_workorder_fila5/laravel/Modules/Intervention/app/Filament/Resources/InterventionResource/Pages/ListInterventions.php
```

**Root Cause:**
- composer.json specifies `larastan/larastan: ^4.0`
- Actual installed version: 3.11.0 (version constraint violation)
- Larastan 3.x incompatible with PHPStan 2.2.13
- Method `isForwardedQueryBuilderMethod()` exists in Larastan 4.x but 3.11.0 version is missing or incorrectly wired

**Solution:**
1. Verify composer.lock is committed and used
2. Force upgrade to Larastan 4.x via `composer update` or install fresh
3. Re-run PHPStan

**Files involved:**
- `laravel/composer.json` (version constraints)
- `laravel/composer.lock` (dependency lock, may be missing)
- `laravel/vendor/larastan/larastan/src/ReturnTypes/EloquentBuilderExtension.php` (line 124: calls `isForwardedQueryBuilderMethod()`)
