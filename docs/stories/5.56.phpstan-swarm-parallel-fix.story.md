# 5.56: PHPStan systematic fix - per-module parallel swarm

## Story

As maintainer, I want PHPStan across all `Modules/*` reduced to zero errors
(phpstan.neon `level: max`) using parallel subagent swarms, with full BMAD
coordination (story → review → dev → test → sync).

## Constraints (standing, non-negotiable)

- Work on current branch `dev` only — never create new branches
- Git forward-only: no revert, no rollback, no checkout (use `git show` to study history)
- No `--force` push
- Never modify `phpstan.neon` — user owns it
- Replace `mixed` with concrete types when possible
- `User` model → `UserContract` / `XotData` methods
- `Profile` model → `XotData` methods
- Update `docs/` in every modified module + theme
- BMAD workflow: create story → review → dev → pest+phpmd+phpinsights → commit → push
- Sync flow: `git add -A && git commit -m "..." && git fetch laraxot dev && git merge laraxot/dev --allow-unrelated-histories -s resolve && git push -u`
- Always git fetch+merge from concurrent agents before starting work

## Per-module loop (swarm pattern)

For each module:
1. **Pre-flight**: read `Modules/<Name>/docs/` (owner wiki) + `git status` + `git fetch laraxot dev` + `git merge laraxot/dev --allow-unrelated-histories -s resolve`
2. **Analyze**: `phpstan analyse Modules/<Name>` → capture error list
3. **Plan**: create/update BMAD story in `Modules/<Name>/docs/stories/`
4. **Fix**: minimal real fixes (no @phpstan-ignore comments, no baseline, no type casts to silence)
5. **Verify per file**: phpstan + phpmd + phpinsights + pest
6. **Pest coverage**: if <80% on touched file, add at least 1 new test
7. **Commit**: forward-only, on `dev`
8. **Sync**: fetch+merge+push (no --force)
9. **Re-verify**: phpstan + phpmd + phpinsights on the module
10. **Update second brain**: append findings to `docs/chat/` and module wiki

## Quality tools

- PHPStan: `./vendor/bin/phpstan` (uses `phpstan.neon`)
- PHPMD: `./tools/phpmd.sh <file>`
- PHPInsights: `./tools/phpinsights.sh`
- Pest: `./vendor/bin/pest Modules/<Name>/tests`
- Pint: `./vendor/bin/pint`
