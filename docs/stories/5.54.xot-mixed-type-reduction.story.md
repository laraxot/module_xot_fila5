# Story 5.54 — Xot: riduzione `mixed` scoperta best-effort

## Contesto

Continuazione locale, scope Xot, della campagna cross-modulo
`5.53.mixed-type-reduction.story.md` (status `in-progress`, ancora aperta al
momento di questa story). Censimento module-locale: 236 file PHP in
`Modules/Xot` con occorrenze di `\bmixed\b` (native type-hint o docblock).

**Collisione con WIP di un'altra sessione**: `git status --short` in
`Modules/Xot` mostrava 1647 file già modificati/non committati (diff netto
+16813/-5854 righe), presenti da prima dell'inizio di questa story (mtime file
2026-09-01/02, ultimo commit locale 2026-09-03; non un processo attivo in
questo istante, ma comunque non spettante a questa story committare per
intero). Per non inglobare accidentalmente quel lavoro incompleto nel commit
di questa story, l'intervento è stato **ristretto ai soli file assenti dal
diff pendente** (109 su 236 file con `mixed`), verificabili con:

```bash
git status --short | awk '{print $2}' > /tmp/xot_dirty.txt
grep -rlE '\bmixed\b' Modules/Xot --include="*.php" > /tmp/xot_mixed.txt
comm -23 <(sort /tmp/xot_mixed.txt) <(sort -t/ /tmp/xot_dirty_prefixed.txt)
```
