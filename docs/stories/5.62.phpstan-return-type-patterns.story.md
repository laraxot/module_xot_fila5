# BMAD Story — PHPStan Return Type Annotation Patterns

## Understand
- **Problema**: PHPStan richiede tipi specifici per array iterabili
- **Errore**: `no value type specified in iterable type array`
- **Soluzione**: Aggiungere `@return array<int, TipoSpecifico>`

## Pattern Library

### Form Components
```php
/**
 * @return array<int, \Filament\Forms\Components\Component>
 */
protected function getFormSchema(): array
```

### Specific Components
```php
/**
 * @return array<int, \Filament\Forms\Components\TextInput|\Filament\Forms\Components\Select>
 */
protected function getFormSchema(): array
```

### Table Columns
```php
/**
 * @return array<int, \Filament\Tables\Columns\Column>
 */
protected function getTableColumns(): array
```

### Actions
```php
/**
 * @return array<int, \Filament\Actions\Action>
 */
protected function getActions(): array
```

## Usage
1. Identificare i tipi concreti restituiti
2. Importare le classi se necessario
3. Aggiungere `@return` PHPDoc annotation
