# BMAD Story — XotBaseResourceTable Architecture Rule

## Understand
- **Problema**: Classi che estendono XotBaseResourceTable hanno metodo `table()` che causa errori
- **Regola architetturale**: Chi estende XotBaseResourceTable NON deve avere il metodo `table()`
- **Causa**: XotBaseResourceTable già definisce table() in modo standardizzato; overridding causa conflitti

## Plan
1. Identificare tutte le classi che estendono XotBaseResourceTable
2. Verificare se hanno metodo table() override
3. Rimuovere metodo table() dove presente
4. Verificare con phpstan + test

## Implement

### Step 1: Trova classi che estendono XotBaseResourceTable
```bash
grep -rn "extends XotBaseResourceTable" Modules/ --include="*.php"
```

### Step 2: Trova chi ha metodo table() override
```bash
grep -rn "function table" Modules/ --include="*.php" | grep -v "XotBaseResourceTable"
```

### Step 3: Verifica che table() sia già in XotBaseResourceTable
Leggere `Modules/Xot/app/Filament/Resources/Tables/XotBaseResourceTable.php`

## Expected Fix
```php
// ❌ Non fare questo
class MyResourceTable extends XotBaseResourceTable {
    public function table(Table $table): Table {  // ERRORE!
        // ...
    }
}

// ✅ Fare questo
class MyResourceTable extends XotBaseResourceTable {
    // Non definire table() - è già in XotBaseResourceTable
}
```
