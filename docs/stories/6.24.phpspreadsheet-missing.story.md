# BMAD Story — PhpSpreadsheet Missing Dependency Fix

## Understand
- **Problema**: `Class "PhpOffice\PhpSpreadsheet\Reader\Csv" not found`
- **Causa**: phpoffice/phpspreadsheet non installato o non caricato
- **Soluzione**: Verificare che phpoffice sia nel composer.json

## Plan
1. Verificare se phpoffice/phpspreadsheet è installato
2. Verificare composer.json
3. Aggiungere se mancante
4. Testare che non ci siano più errori bootstrap

## Implement

### Step 1: Check installazione
```bash
composer show phpoffice/phpspreadsheet
```

### Step 2: Check in composer.json
```bash
grep "phpoffice" composer.json
```

### Step 3: Se mancante, aggiungere
```bash
composer require phpoffice/phpspreadsheet --no-interaction
```

- [ ] `composer show phpoffice/phpspreadsheet` funziona
- [ ] PHPStan bootstrap non ha più errori PhpSpreadsheet
