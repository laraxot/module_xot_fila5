# Story 18.55 - Prompts catalog audit and execution

## Context

`bashscripts/docs/prompts/` holds 211 files (56k lines): 99 markdown files contain dates in
the body, 4 have changelog sections, 20 or more `.txt` twins of `.md` files survive although
`INDEX.md` states the conversion is complete. The directory is ignored by both the root repo
(`bashscripts/`) and the bashscripts repo (`docs/`), so it is not versioned: a tar backup is
taken before any edit (`/tmp/marker-backup/prompts-backup-*.tgz`).

User rule: prompts carry no dates and no changelog. Knowledge with a date belongs to the
wiki or to a story, not to the prompt.

## Owned scope

`bashscripts/docs/prompts/**` only. Execution of operational prompts targets
`laravel/Modules/Restaurant` and records evidence in `laravel/build/` and in the module stories.

## Tasks

1. Inventory: duplicates (`.md` / `.txt`, `NN-x.md` / `NN-y.md`), dead links, prompts that
   contradict the wiki canon (services, plain migrations, `->label()`).
2. Cleanup: remove dates and changelog blocks from every prompt (move dated facts to the
   wiki when still true), delete `.txt` twins, fix frontmatter, rebuild `INDEX.md`.
3. Consolidate near duplicates into one canonical prompt each; mark the others superseded.
4. Execute the operational prompts against `Modules/Restaurant` in order: quality gates
   (03), migrations audit (33), factories/seeders audit (34), policies (35), filament audit
   (06), translations (21), docs (12/44), boy scout (24).

## Acceptance criteria

`grep -lE '20[0-9]{2}-[01][0-9]-[0-3][0-9]' bashscripts/docs/prompts/*.md` returns nothing
except explicit examples; no `.txt` twin; `INDEX.md` lists every prompt once; execution
evidence linked from the Restaurant stories.
