## Summary

After all module fixes (stories 6.1-6.6) complete, consolidate all changes into root repo.

Each module has independent .git → must coordinate commits + pushes across 54 repos.

## Problem

- 54 independent module git repos
- Each module pushes separately (git add/commit/push per module)
- Root repo must pull all changes
- Risk: dangling refs, merge conflicts, partial consolidation

## Solution

**Phase 1: Verify all module commits (5 min)**
```bash
for mod in Modules/*/; do
  cd "$mod"
  git log --oneline -1
  cd ../..
done
```
All should show recent commits from Epic 6 stories.

**Phase 2: Pull all module changes into root (10 min)**
```bash
git fetch --all  # fetch from all remotes
git status       # verify clean or show conflicts
```

**Phase 3: Merge with care (10 min)**
```bash
# For each module remote:
git merge <module-remote>/<branch> --allow-unrelated-histories

# Resolve conflicts if any (rare, independent histories)
# git add conflicted-file && git commit
```

**Phase 4: Root repo commit (5 min)**
```bash
git add -A
git commit -m "Root consolidation: all modules Epic 6 fixes merged"
git push -u origin dev  # (or main, per standing order)
```

**Phase 5: Final verification (10 min)**
```bash
./vendor/bin/phpstan analyse Modules --level 10  # should show 0 errors
git log --oneline --graph --all | head -20       # verify merge tree
```
