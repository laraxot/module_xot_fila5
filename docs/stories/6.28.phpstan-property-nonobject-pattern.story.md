# BMAD Story — PHPStan Property NonObject Fix Pattern

## Understand
- **Errore**: `property.nonObject` - 139 occorrenze
- **Causa**: Accesso a proprietà su non-oggetti (mixed, null)
- **Soluzione**: instanceof check o null-safe operator

## Pattern Library

### Pattern 1: Null-safe Property Access
```php
// ❌ Errato
$name = $record->name;

// ✅ Corretto
$name = $record?->name ?? '';
```

### Pattern 2: Property with Type Check
```php
// ❌ Errato
$value = $obj->property;

// ✅ Corretto
if (is_object($obj)) {
    $value = $obj->property;
}
```

### Pattern 3: isset Check
```php
// ❌ Errato
$value = $data['key'];

// ✅ Corretto
$value = $data['key'] ?? null;
```
