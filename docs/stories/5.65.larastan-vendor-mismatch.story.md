# BMAD Story — Larastan Vendor Mismatch Fix

## Understand
- **Problema**: PHPStan Internal Error `isForwardedQueryBuilderMethod()`
- **Causa**: Versione vecchia di larastan in `Modules/Xot/vendor/larastan/`
- **Soluzione**: Rimuovere vendor duplicato e usare quello root

## Plan
1. Verificare che root vendor sia aggiornato
2. Rimuovere `Modules/Xot/vendor/larastan/`
3. Rieseguire composer update
4. Verificare PHPStan

## Implement
```bash
# 1. Verificare versione
composer show larastan/larastan

# 2. Rimuovere duplicato
rm -rf Modules/Xot/vendor/larastan

# 3. Aggiornare
composer update --with-all-dependencies

# 4. Verificare
./vendor/bin/phpstan analyse Modules
```

## Verify
- [ ] `composer show larastan/larastan` -> v3.11.0
- [ ] PHPStan non ha più errori `isForwardedQueryBuilderMethod`
- [ ] Nessun Internal Error

## Status
- [x] Root cause identificata
- [x] Fix applicato (composer update --with-all-dependencies)
- [x] PHPStan funziona

## Lessons Learned
- Mai tenere vendor duplicati nei moduli
- composer.json root è la fonte della verità per le dipendenze
- Modules/*/vendor/* non dovrebbe esistere per pacchetti che sono già nel root
