# Code Style Preferences

## Array Formatting
- **Una chiave per riga**: ogni voce dell'array deve essere su una riga separata
- **Formato preferito**:
  ```php
  'create' => [
      'label' => 'create',
      'icon' => 'create',
      'tooltip' => 'create',
  ],
  ```
- **Formato NON preferito**:
  ```php
  'create' => ['label' => 'create', 'icon' => 'create', 'tooltip' => 'create']
  ```
- **Regola**: ogni chiave dell'array deve avere la sua riga dedicata, con indentazione corretta
