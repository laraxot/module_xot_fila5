# Code Style Preferences

## Array Formatting

- **Una chiave per riga (SEMPRE, ordine utente 2026-09-16)**: ogni voce dell'array
  deve essere su una riga separata — **anche** i nested.
- **Formato preferito**:
  ```php
  'create' => [
      'label' => 'create',
      'icon' => 'create',
      'tooltip' => 'create',
  ],
  ```
- **Formato NON preferito**:
  ```php
  'create' => ['label' => 'create', 'icon' => 'create', 'tooltip' => 'create']
  ```
- **Writer**: `Modules\Xot\Actions\Arr\SavePhpArrayAction` (non VarExporter raw —
  compatta i nested). Story [`bmad/stories/5.155-php-array-one-key-per-line.story.md`](bmad/stories/5.155-php-array-one-key-per-line.story.md).
- **Always-on**: `.cursor/rules/php-array-one-key-per-line.mdc`
- **Expand**: `php bashscripts/tools/expand-lang-arrays-one-key-per-line.php --module=Name`
