## Come è organizzato questo indice

`docs/` contiene sia materiale attivo sia un grosso debito storico accumulato da sessioni passate (numerosi file quasi-duplicati con nomi in `kebab-case` vs `snake_case`, più tentativi di indice concorrenti come `00-index.md`, `00-INDEX.md`, `01-index-details.md`, ecc.). Per dare comunque una struttura navigabile per argomento, senza spostare o cancellare nulla:

1. **Sezioni per argomento** (sotto): includono sia i file già organizzati in sottocartelle tematiche (es. `docs/filament/`, `docs/phpstan/`) sia i file sciolti direttamente in `docs/` classificati per parola chiave nel nome file. La classificazione per parola chiave è euristica, non perfetta: un file può comparire nella sezione "vicina" invece di quella ideale.
2. **Da classificare**: file sciolti in `docs/` che non hanno intercettato nessuna parola chiave nota. Restano linkati, non persi.
3. **Storico / da consolidare**: cartelle che sono chiaramente dump storici o mirror duplicati (`archive/`, `consolidated/`, `historical/`, `raw/`, `root-md-files/`, `root-txt-files/`, `-integration/`, `_integration/`, `old_tasks/`). Non enumerate file per file (troppo numerose e in larga parte doppioni dei file già linkati sopra); riportato solo un conteggio e un link alla cartella.

Nota: dentro molte sezioni tematiche esistono anche sotto-cartelle `archive/` locali (es. `actions/archive/`, `filament/archive/`) con versioni precedenti dello stesso contenuto: sono incluse nella sezione del topic ma vanno considerate storiche rispetto al file principale con lo stesso nome.

- Generato con uno script PHP one-off (non committato) che cammina `docs/`, esclude le cartelle storiche elencate sopra, e classifica il resto (sottocartelle tematiche + file sciolti in root) per parola chiave nel path/nome file.
- I titoli mostrati sono il primo `# Titolo` trovato nel file (fallback: nome file) — non è stato validato il contenuto di ogni singolo file.
- Nessun file `.md` è stato spostato, rinominato o cancellato in questo audit.
- Non toccati file `.php` o altro codice del modulo (sessione parallela in corso su `app/Filament/Traits/HasXotTable.php`).
